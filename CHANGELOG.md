# Changelog

## 1.0.1 — 2026-10-28

- Added the qdran.de logo to the bottom-right of the settings screen. Click it to open qdran.de.
- Minor bug fixes.

## 1.0.0 — 2026-10-28

- Expanded the original 1.21.11 release with separate Fabric jars for Minecraft 1.21.4, 1.21.8, 26.1.x, 26.2 and 26.3.
- Included only TierMC and SubTiers on every version, with their own gamemode icons.
- Included configurable nametags and tab ranks, player profiles, highest-tier selection, saved tier results, online players, leaderboards, comparisons and clickable chat names.
- Included optional own-name rendering in F5 and a movable opponent HUD with a saved position.
- Verified local dev-client startup, fixture nametags, settings and HUD rendering on 1.21.4, 1.21.8, 26.1.2, 26.2 and 26.3. Drag handlers and position persistence were additionally checked on 1.21.4 and 26.3.
- Reworked the README with per-version downloads, installation steps, screenshots, commands and all eight TierMC Discord links.

The original Minecraft 1.21.11 jar was released on 2026-10-27. This update keeps that download under the same 1.0.0 release. Tests used local dummy ranks; live APIs and server-specific nametags were not validated in this test pass.
